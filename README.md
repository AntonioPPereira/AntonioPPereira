### [Pereira Worlds](https://github.com/AntonioPPereira/PereiraWorlds)

Meu portfólio — construído como software, não como página. Sem scroll: uma pilha
de camadas fixas sobre quatro cenas em 4K que nunca cortam para preto, com a
navegação funcionando como máquina de estados entre elas.

Dentro dele, dois jogos com engine escrita do zero em Canvas 2D — loop de
timestep fixo, colisão própria e frame data de verdade. A regra que guia a
arquitetura inteira: **o React nunca re-renderiza a 60fps.** O GSAP anima objetos
crus e as camadas de WebGL e Canvas leem esses valores a cada frame.

<sub>Next.js · React · TypeScript · Three.js · GSAP · Motion · Tailwind</sub>

Sistemas em produção na **Corcovado Geosub**, onde fui responsável pela direção
de front-end e da arquitetura. Repositórios privados — os detalhes técnicos e as
demos em vídeo estão no portfólio.

| Sistema | O que faz |
| --- | --- |
| **AIS Web** | Entrega de dados AIS para a Petrobras via HTTPS, no formato XML exigido pelo Apêndice D. Banco-espelho com privilégio mínimo, replicação por TLS e carta náutica 3D com replay temporal da frota. |
| **Suprimentos** | Fluxo completo de requisição e compra (PRC → aprovação em níveis → POC), com controle de acesso por grupos do Azure AD e rastreabilidade total do pedido. |
| **Treinamentos** | Conformidade de certificações obrigatórias da operação offshore — matriz colaborador × treinamento, exigências por função e alertas de vencimento. |
